## Features

- **Player & zombie tracking** – real‑time 2D boxes with name and distance indicators[reference:0].
- **Loot ESP** – highlight weapons, food, medical supplies, and containers with custom colours[reference:1].
- **Distance‑based colour coding** – entities shift colours based on range for quick threat assessment.
- **Adjustable render distance** – control how far entities are displayed to optimise performance.
- **Skeleton overlay** – optional bone display for precise targeting[reference:2].
- **Animal & vehicle tracking** – visual markers for wildlife and cars[reference:3].
- **Weather‑resistant rendering** – works in any lighting or weather condition[reference:4].
- **Customisable opacity and colours** – personalise every element via simple config files.
- **Performance‑first design** – lightweight rendering for stable FPS even on mid‑range systems.
- **Step‑by‑step setup guide** – PDF with screenshots and common troubleshooting tips.

## Requirements

- Windows 10 / 11 (64‑bit)

- Any screen resolution (auto‑scaling supported)

## Usage

1. Download and extract the package.
2. Copy the preset files to your DayZ configuration folder as described in the guide.
3. Launch DayZ in borderless windowed mode.
4. Press the designated hotkey (`F1`–`F4`) to cycle through visual profiles.
5. Use the included colour palette editor to customise entity markers.
6. Adjust render distance and opacity via the settings panel.

## About the project

PLAYER-ESP-DAYZ is a curated collection of overlay configuration templates and visual reference materials for DayZ survivors. It demonstrates how non‑invasive visual aids can improve spatial awareness, loot efficiency, and threat prioritisation in the harsh post‑apocalyptic world. All templates are designed for external rendering and UI customisation, strictly for educational and training purposes.
